# حديقة التعلّم — Learning Garden (PWA)

لعبة تعليمية تفاعلية للأطفال (4–8 سنوات) لتعلّم الحروف العربية، الأرقام، والألوان — قابلة للتثبيت كتطبيق على الهاتف أو الحاسوب.

## هيكل المشروع
```
index.html          نقطة الدخول
css/style.css        كل التنسيقات
js/app.js            محرك اللعبة، البيانات، والمنطق
manifest.json         بيانات التطبيق (الاسم، الأيقونات، الألوان)
service-worker.js     التخزين المؤقت للعمل بدون إنترنت
icons/                أيقونات التطبيق (عادية + maskable لأندرويد)
```

## تشغيل محلي
متصفحات الهاتف تتطلب أن يكون الموقع مخدوماً عبر HTTP/HTTPS (وليس فتح الملف مباشرة) حتى يعمل Service Worker والتثبيت. أسهل طريقة:

```bash
cd pwa
python3 -m http.server 8080
```
ثم افتح `http://localhost:8080` من المتصفح (أو من هاتف على نفس الشبكة عبر عنوان IP جهازك).

## النشر على الإنترنت
ارفع محتوى مجلد `pwa/` كما هو إلى أي استضافة ثابتة (GitHub Pages، Netlify، Vercel، Cloudflare Pages...) — يجب أن يكون عبر **HTTPS** حتى يعمل التثبيت على iOS وAndroid.

## التثبيت على الجهاز
- **Android / Chrome:** ستظهر رسالة "إضافة إلى الشاشة الرئيسية" تلقائياً، أو من قائمة المتصفح ⋮ ← "تثبيت التطبيق".
- **iPhone / Safari:** من زر المشاركة 📤 ← "إضافة إلى الشاشة الرئيسية".
- **Desktop / Chrome:** أيقونة التثبيت ⊕ تظهر في شريط العنوان.

بعد التثبيت الأول، تعمل اللعبة بدون إنترنت لأن Service Worker يخزّن كل الملفات محلياً.

## البيانات المحفوظة
تقدّم الطفل (النجوم، المستويات المكتملة، الإعدادات) يُحفظ في `localStorage` على نفس الجهاز/المتصفح — لا يوجد خادم أو حساب مطلوب.

## التطوير لاحقاً
- `js/app.js` يحتوي على بيانات كل محطة (`LEVELS`) بشكل منفصل عن محرك العرض، فإضافة محطة جديدة (إنجليزي، رياضيات...) تكون بإضافة بيانات فقط دون تعديل المحرك.
- لرفع رقم الإصدار بعد أي تعديل مستقبلي، غيّر `CACHE_NAME` في `service-worker.js` (مثلاً `learning-garden-v2`) حتى يحدّث المتصفح الملفات المخزّنة.
